Date: October 12, 2026 (America/Los_Angeles).

## Scope and acceptance

Beginner CFOP now shares the cube engine, validated scramble/color input, trace recorder and player with LBL. Its independent rules build a direct white-bottom cross, solve connected corner-edge pairs, apply two-look OLL and two-look PLL, and finish with AUF. LBL retains the yellow-center daisy route.

**The owner confirmed physical-cube CFOP teaching acceptance on October 12, 2026**, after using the published preview. This records the owner's overall acceptance; it does not claim independently observed per-case trials. Subsequent releases of this accepted method can use `publish_preview=false` and `teaching_accepted=true`. Earlier dated LBL and color-entry acceptance records remain available in their validation documents.

## Browser and release procedure

Run the browser suites sequentially because they share `test-results/`:

```sh
npm run typecheck
npm run test:unit
npm run test:corpus
npm run build
npm run test:e2e
npm run test:production
git diff --check
```

On Windows, use `npm.cmd`/`npx.cmd`. This isolated checkout uses port 5183 for development tests and 5184 for the production preview. Both GitHub workflows already execute the expanded corpus command and both browser suites.

Release verification checks all 54 rendered starting colors against an independent asymmetric fixture for scramble and entered-color solves, then checks the native renderer's solved state. It also covers `/cube-steps/`, refreshed hash routes, method switching, every lesson/case selector, 390px keyboard use, camera orbit and no-WebGL text fallback. Final screenshots must capture a visible, painted WebGL surface; a full-page screenshot of an offscreen lazy canvas is not visual evidence of rendering.

## Owner physical-cube check

The following is the original acceptance checklist. Overall acceptance is now confirmed above; individual trials were not separately reported by the owner.

- [ ] Follow a direct-bottom-cross example while matching side centers.
- [ ] Follow F2L examples including white up, a trapped edge with a solved corner, both insertion hands, and three already-completed pairs.
- [ ] Follow dot OLL and representative corner OLL patterns from their stated holding frames.
- [ ] Follow adjacent/diagonal corner permutation and H/Z, confirming M direction and restored centers.
- [ ] Complete one scramble solve and one six-face entered-color solve, including any final AUF.
- [x] Record the owner's confirmation before changing CFOP teaching acceptance.

Real-device touch and assistive-technology sessions remain unverified. Input uses the documented fixed center scheme. Full PLL, full OLL, Roux, ZZ and camera scanning remain future versions. Sampled scramble coverage and finite-case checks are strong regression evidence, not a proof over every legal cube state.
