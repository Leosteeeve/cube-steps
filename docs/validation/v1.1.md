## Reproduce

```sh
npm ci
npm run typecheck
npm run test:unit
npm run test:corpus
npm run build
npm run test:e2e
npm run test:production
```

On Windows use `npm.cmd`/`npx.cmd`. Local worktree browser tests use `CUBESTEPS_TEST_PORT=5183` so they cannot accidentally reuse the original checkout's server on 5173. Production checks use a separate preview port. Default development and CI ports remain unchanged.

The Windows sandbox blocked Git Bash's IPC setup and the offline dependency cache. Recorded successful setup/testing used the host runtime outside that sandbox. Browser tests may print the host's pre-existing `NO_COLOR`/`FORCE_COLOR` warning; this is separate from page errors and asset failures.
