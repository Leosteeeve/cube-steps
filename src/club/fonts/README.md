# Self-hosted club fonts

Retrieved 2026-10-28 from Google Fonts CSS2. Unmodified Latin WOFF2 subsets, with SIL OFL 1.1 notices retained here and in public/licenses/club-fonts. No external requests occur at runtime.

Bricolage Grotesque uses a static 600 weight at optical size 48 for headings. Instrument Sans uses static 400/600/700 weights for body and controls. Static subsets avoid the inconsistent variable-font weights observed in our Windows WebKit screenshots. IBM Plex Mono remains the notation face.
